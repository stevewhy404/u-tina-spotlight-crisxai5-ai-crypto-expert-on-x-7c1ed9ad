An original spotlight graphic introducing @crisxai5 (https://x.com/crisxai5) as a must-follow AI & crypto expert — practical insights on AI agents, crypto alpha, Web3 tooling and on-chain automation.

`main.ts` copies `POST.json` from the repository to `$MAKEFUN_OUTPUT_DIR` (stdlib only, deterministic). The post itself is the entry: its public X engagement (likes + reposts + quotes) decides the places.

The graphic `spotlight.png` (1600×1600) was generated by the agent in this session. The draft post text is in `POST-DRAFT.txt`; `POST.json` holds the placeholder until the user posts from their own X account and sends the real post URL.
